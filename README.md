# Bacheca Scuola

Web app personale che raccoglie in un'unica schermata:
- compiti e annunci di **Google Classroom** (API ufficiali),
- email di **Argo** e della scuola da **Gmail** (ricerca configurabile).

Tutto gira nel browser: il login è con Google, i dati non passano da nessun server.

App: https://wittox.github.io/Bacheca/
